# Anime-Recommendation-System.
With the surge of digital entertainment platforms, there's an abundance of anime available, and finding suitable and personalized recommendations has become quite a challenge. In this study, a hybrid anime recommendation system is proposed, which combines popularity-based filtering, content-based filtering, collaborative filtering and Graph Attention Networks (GAT) aiming to increase the accuracy of the recommendations, the diversity of the recommendations and the learning of relationships.
The system to be implemented is based on the user interaction information and the anime metadata such as the genre, rating, etc., to provide meaningful recommendations. The popularity-based filtering guarantees that the most popular and trending content is included, and the content-based filtering captures the similarities in features among the anime. Collaborative filtering is a technique that uses patterns from the previous user interactions.
The key is to improve the quality of the recommendations by modeling the user and the anime as a graph, with anime as the nodes and user-anime interactions as the edges, using a Graph Attention Network (GAT). The GAT is able to propagate information across connected nodes to account for more contextual and structural information in order to provide improved recommendations.
To overcome the drawbacks, all of the approaches are integrated in a hybrid approach with a corresponding hybrid score used. Evaluation of the model is done using ranking based and beyond-accuracy measures such as Precision, Recall, F1-score, Hit Rate, MRR, NDCG, Diversity, Novelty, Coverage. 
The experimental results indicate that the proposed hybrid model can achieve better recommendation performance by providing relevant suggestions for anime shows which are personalized, diverse, and context-aware. The solution is scalable, can be applied to other sectors like movie recommendations, ecommerce, and music streaming, and can enrich general user engagement and experience.
